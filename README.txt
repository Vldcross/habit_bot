Бот привычек: бесплатная работа через Cloudflare Workers

ОСНОВНОЙ ВАРИАНТ — БЕСПЛАТНЫЙ

Cloudflare Workers Free принимает webhook Telegram. D1 Free хранит цели,
прогресс и шаги настройки. Cron Triggers запускает напоминания с 21:00
по Москве. Постоянно включённый компьютер, платный сервер и домен не нужны.
Конфигурация платного Render удалена; платные ресурсы не создавались.

У Free есть лимиты: Workers — 100 000 запросов в день и 10 мс CPU на вызов.
На Free превышение квот D1 приводит к ошибкам запросов, а не к автоматической
платной подписке. Для личного использования лимитов обычно достаточно;
фактическое потребление смотрите в панели Cloudflare. Выбирайте Workers Free,
не включайте Workers Paid. Гарантировать отсутствие сбоев бесплатный тариф
не может. Официальные условия:
https://developers.cloudflare.com/workers/platform/pricing/
https://developers.cloudflare.com/d1/platform/pricing/

КАК РАЗВЕРНУТЬ

1. Создайте бесплатный аккаунт на https://dash.cloudflare.com/.
   Откройте Workers & Pages и выберите бесплатный поддомен workers.dev.
2. Скопируйте Account ID из панели аккаунта. Создайте API Token с правами
   Account -> Workers Scripts -> Edit и Account -> D1 -> Edit
   только для выбранного аккаунта.
3. В защищённых настройках среды задайте:
   CLOUDFLARE_ACCOUNT_ID — идентификатор аккаунта, не секрет;
   CLOUDFLARE_API_TOKEN — API-токен Cloudflare;
   BOT_TOKEN — токен нужного Telegram-бота.
   Прежний токен опубликован в истории Git: перевыпустите его в @BotFather.
   Не отправляйте значения токенов в чат, не добавляйте их в репозиторий.
4. В каталоге проекта с Node.js 24 LTS:
   npm ci
   npm test
   npm run build
   npm run deploy:free

Скрипт проверяет код и BOT_TOKEN, создаёт или использует D1 habit-bot-free,
применяет схему без удаления существующих таблиц, загружает Worker, передаёт
секреты через stdin в защищённое хранилище Cloudflare и проверяет /health.
Только после успешной проверки он меняет webhook Telegram, сохраняя очередь
обновлений. Новый WEBHOOK_SECRET генерируется в памяти; в файлы не записывается.
Домен workers.dev и Account ID не являются секретами.
Обычная команда npm run build делает только dry-run и ничего не публикует.
wrangler.json содержит нулевой database_id для локальной проверки;
deploy:free создаёт фактическую конфигурацию в игнорируемом .local/.
Не используйте прямой wrangler deploy с нулевым database_id.

Остановите прежний polling-процесс или webhook-сервис перед переходом,
чтобы он не перехватывал сообщения и не менял webhook обратно.
Данные на прежнем сервере автоматически не переносятся. Для существующих
целей сначала экспортируйте их с прежнего хостинга и импортируйте в D1.
Повторный deploy:free сохраняет уже существующие цели в той же базе D1.
Публикация среды разработки Codex сама по себе не публикует Worker.

ПРОВЕРКА ПОСЛЕ РАЗВЁРТЫВАНИЯ

В личном чате с ботом нажмите /start, откройте ⚙️ Настройки и задайте цель.
Нажмите «Да» дважды: день и сумма должны начислиться один раз.
Откройте статистику. Повторный /start не обнуляет прогресс.
Следующее начисление доступно в новый календарный день по Москве.
Настройки и незаконченный ввод сохраняются даже между запусками Worker.
/cancel отменяет ввод; /reset_all удаляет вашу цель; /help показывает команды.
Напоминания идут с 21:00 по Москве, партиями по 20 адресатов в минуту,
если цель не завершена и сегодняшний день ещё не отмечен.
Это схема для небольшого бота: за час обрабатывается до 1200 адресатов.
Сбои доставки повторяются в этом окне; заблокировавшие бота чаты исключаются
до нового входящего сообщения. Ошибка картинки не отменяет прогресс.

РАЗРАБОТКА И ПРОВЕРКИ

Node.js 24 LTS, npm ci, затем npm test и npm run build.
Тесты выполняют настоящий SQL на SQLite: команды, настройка, отмена,
валидация чисел, идемпотентность повторной доставки, атомарность сохранения,
московская дата, напоминания, повторы при ошибках и ограниченные партии.
Реальные сообщения Telegram в тестах не отправляются.
Для локальной D1:
   npx wrangler d1 execute DB --local --file cloudflare/migrations/0001_init.sql --yes
Для локального сервера:
   npm run dev
Локальные секреты можно задать в .dev.vars по образцу .dev.vars.example;
этот файл игнорируется Git. Не используйте реальные webhook-сообщения против
локального адреса, он недоступен серверам Telegram.

PYTHON-ВЕРСИЯ

bot.py сохранён для локального запуска и собственного сервера с Python 3.12:
   python3 -m venv .venv
   .venv/bin/python -m pip install -r requirements.txt
BOT_TOKEN задаётся в окружении, DATA_FILE — путь к постоянному JSON-файлу.
Файл .env автоматически не загружается.
   PYTHON_BIN="$PWD/.venv/bin/python" ./start.sh --check
   PYTHON_BIN="$PWD/.venv/bin/python" ./start.sh
   .venv/bin/python -m unittest discover -s tests -v
Этот процесс работает, пока запущен его компьютер/сервер. Не запускайте
его одновременно с Cloudflare webhook. RESET_WEBHOOK_ON_START=true
нужен только для отдельного согласованного перехода назад на polling.
